# 🌈 Daily Dashboard

모던하고 아름다운 반응형 개인 대시보드 웹 애플리케이션입니다.

## ✨ 주요 기능

- **실시간 날씨 & 위치**: Geolocation 및 OpenWeather API 기반 실시간 기상 상태 및 기온 제공
- **실시간 시계 & AI 명언**: 실시간 시계와 Google Gemini AI 기반 동적 동기부여 명언 생성
- **뽀모도로 포커스 타이머**: 25분 집중 인터벌 타이머
- **D-Day 목표 캐러셀**: 주요 마일스톤 및 목표 D-day 카운트다운
- **Today Focus (오늘의 핵심)**: 오늘 가장 중요한 핵심 테스크 설정 및 로컬스토리지 연동
- **오늘의 기분 트래커**: 평온, 기쁨, 몰입 등 당일 감정 상태 기록
- **할 일 목록 (Todo List)**: 진척률(완료/전체)이 표시되는 인터랙티브 투두 리스트
- **아이디어 대시패드**: 자동 저장 인디케이터가 포함된 자유로운 생각 및 메모 공간

## 🛠️ 기술 스택

- **Frontend**: React 19, Vite, Vanilla CSS (Glassmorphism UI)
- **Icons**: Lucide React
- **AI Integration**: Google GenAI SDK (`@google/genai`)
- **Deployment**: GitHub Pages (GitHub Actions), Vercel
